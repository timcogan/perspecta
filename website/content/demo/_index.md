## About this preview

Drop DICOM files onto the viewer or choose **Open DICOM(s)** from the menu. Perspecta processes them locally in browser memory; it does not upload or save them.

This is an evaluation preview, not a medical device, and is **not for diagnostic use**.

Browser limits: 512 MiB per file, 1 GiB retained per session, and 192 megapixels of retained images. The browser preview does not support JPEG 2000, JPEG-LS, or DICOMweb; see the desktop release for the complete workflow.
