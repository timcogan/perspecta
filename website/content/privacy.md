Most pages on this site use Google Analytics 4 (GA4) to understand how the public website is used. The [browser technical preview](/demo/) is deliberately isolated: it does not load GA4, analytics, a cookie banner, tracking pixels, advertising code, or third-party runtime scripts.

What GA4 collects:
- Usage data such as page views, device/browser info, and general location (approximate).
- Perspecta does not send DICOM files or DICOM metadata to GA4.

Legal basis:
- Analytics cookies are only enabled after you give consent via the cookie banner.

How to withdraw consent:
- Use the "Manage cookies" link in the footer and choose "Decline".

Data sharing:
- Analytics data is processed by Google on our behalf.

## Browser technical preview

Files manually selected or dropped on the browser preview are read locally in browser memory. Perspecta does not upload those files, save them to local storage or IndexedDB, include their contents in logs, or send them to an analytics service. The page fetches its static JavaScript and WebAssembly application files from the same Perspecta origin. Closing or reloading the page clears the current session.

The preview has no public file-upload API, URL-import API, DICOMweb connection, cross-window messaging interface, or automated file-access endpoint. A person must select or drop each local file in the browser. Users remain responsible for following their organization's privacy and data-handling rules when choosing files.

The browser viewer is a technical preview for evaluation and development. It is not a medical device and is not for diagnostic use.

If you have questions, contact the site owner.
